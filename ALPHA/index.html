Spotify

URL: https://open.spotify.com

This is Spotify’s public-facing web player where users browse playlists, albums, and recommendations.

Object Location

The object is a playlist card on the Spotify Home page. A user locates it by:

  • Opening Spotify Web Player
  • Landing on the Home tab (default)
  • Scrolling through sections like Made For You, Your Top Mixes, Daily Recommendations, etc.
  • Each playlist appears as a rectangular card with:
    • Cover art
    • Playlist title
    • Creator name
    • The playlist card is visually grouped in horizontal rows, making it easy to scan.

TRIGGERS

The microinteraction begins when the user hovers their cursor over a playlist card. This hover event is the trigger.

RULES (Existing Microinteraction)

  1. Reveal play button- When the cursor enters the playlist card area, Spotify checks if the card is hover‑active. If true, it displays a floating Play button in the bottom-right corner of the card.
  2. Card highlight- The playlist card slightly brightens toshow that the card is clickable.

FEEDBACK

What the user sees when hovering:

  • A green circular Play button fades in
  • The playlist card background increases brightness
  • The cursor changes to a pointer
  • The card feels “active” and ready to be clicked
  • There is no sound feedback because this is a web interaction.

LOOPS

What the user sees when hovering:

  • Every time the user hovers over a playlist card, the Play button appears.
  • When the cursor leaves, the Play button disappears.
  • the background brigthens

MODES

What the user sees when hovering:

  • Logged-in mode: Hovering shows the play button and allows playback.
  • Logged-out mode: Hovering still shows the visual hover effect, but clicking redirects the user to the login page instead of playing music.
  • Mobile mode: There is no hover interaction because mobile devices rely on tap events. The Play button is always visible or appears on tap.
